# 🚢 피클마린트래킹 (Pickle Marine Tracking)

원료·제품 운반선을 한 화면에서 지켜보는 **해상 관제 웹앱**입니다. 지도 위 실시간 항적과 함께, 담당 AI 비서가 **5단계 표준 브리핑**을 말풍선으로 차례대로 읽어 줍니다.

- **바로 열기**: https://youngwon1066-max.github.io/Sung/
- 설치 없이 브라우저에서 열리고, 갤럭시(안드로이드) 홈 화면에 **PWA 앱**으로 추가할 수 있습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| 🗺️ 해상 지도 관제 | Leaflet + OpenStreetMap 기반. API 키 없이 동작하며 선박 위치·과거 항적·예상 항로를 표시합니다. |
| 💬 5단계 표준 브리핑 | ① 현재 위치 → ② 속도·침로 → ③ 화물·흘수 → ④ 도착 예정일(ETA) → ⑤ 부두 접안·통항 조건 |
| 🧭 회랑 우회 항로 | 울산↔여수(남해 외해), 여수↔서해(고흥·여수반도 관통 방지) 구간을 실제 해로에 맞춰 곡선으로 그립니다. |
| ⚡ 감속 사유 진단 | 11~13노트 순항 대비 저속일 때 투묘·계류·Eco Steaming·협수로 제한속도 등 원인을 문장으로 설명합니다. |
| 🔄 데이터 분리·자동 갱신 | 선박 데이터는 `data/fleet.json` 하나에. 페이지를 열 때·[🔄 새로고침]·5분마다 `no-store`로 다시 받아 지도와 카드를 갱신합니다. |
| 🕒 데이터 기준시각 | 헤더에 `fleet.json`의 `updatedAt`(KST)을 표시합니다. 서버를 못 받으면 "내장 데이터 표시 중"으로 알려 줍니다. |
| 🔎 선박 검색·추가 | 선박명 또는 IMO 번호로 조회해 관제 목록(칩)에 추가, `×`로 관제 종료. |
| 🥒 담당 피클 교체 | 비서 이름·호칭·자음 캐릭터·테마 컬러를 바꾸고, `?agent=이름&user=호칭&consonant=ㅇ&color=%23c084fc` 링크로 동료에게 그대로 공유. |
| 📱 반응형 UI | 폰 세로 화면부터 태블릿·폴더블 2단 화면(지도 / 브리핑 탭 전환)까지 대응. |
| 📲 PWA | 매니페스트 + 서비스 워커(v3). 홈 화면 추가 시 전체 화면(standalone)으로 실행, 앱 셸과 마지막 선박 데이터는 오프라인에서도 열립니다. |

## 🗂 선박 데이터 갱신 방법

선박 위치·항로·브리핑 문구는 **`data/fleet.json` 한 곳**에서 관리합니다. `index.html`은 화면·로직만 담당하므로, 데이터만 고쳐 푸시하면 앱에 그대로 반영됩니다.

```jsonc
{
  "updatedAt": "2026-11-27T14:11:48+09:00",   // 헤더에 표시되는 데이터 기준시각 (KST)
  "fleet": [
    {
      "id": "du-juan", "name": "DU JUAN", "imo": "9342035",
      "lat": 34.6326, "lon": 122.9639, "speed": 10.8,
      "course": "187° SSW (남남서진)", "draught": "6.0m (만재)",
      "origin": { "name": "…", "lat": 37.27, "lon": 119.20, "time": "11/25 18:37 출항" },
      "dest":   { "name": "…", "lat": 24.2672, "lon": 120.5065, "eta": "타이중 11/30 01:00 KST" },
      "pilotRule": "…", "yeosuInbound": true,
      "observedAt": "2026-11-27T08:51:00+09:00",
      "status": "tracking",            // 추적이 끝난 배는 "completed"
      "pastRoute": [[37.27, 119.20]],  // 지나온 항로 (실선)
      "futureRoute": [[34.63, 122.96]],// 앞으로 갈 항로 (점선)
      "briefings": [                   // 5단계 브리핑 문구 (선택, 없으면 기본 문구)
        { "tag": "📍 1. 현재 위치", "time": "{observedAt} AIS 수신", "text": "…{name} …{lat} …{lon}…" }
      ]
    }
  ]
}
```

- `briefings` 문구에서 쓸 수 있는 치환자: `{name}` `{nameKo}` `{lat}` `{lon}` `{lat2}` `{lon2}` `{speed}` `{course}` `{draught}` `{cargo}` `{eta}` `{destName}` `{originName}` `{pilotRule}` `{uName}` `{observedAt}` `{speedAnalysis}`
- 6시간 주기 운항 추적(`scheduled-actions/두-주안-호-운항-추적`, `유란-호-운항-추적`)이 해당 선박 항목과 `updatedAt`을 갱신해 푸시합니다.
- 내장 사본(네트워크 실패 시 사용)은 아래 명령으로 `fleet.json`과 동기화합니다.

```bash
python3 tools/sync_fallback.py        # fleet.json → index.html 내장 사본
python3 tools/sync_fallback.py --now  # updatedAt을 현재 KST로 바꾼 뒤 동기화
```

- 사용자가 화면에서 `×`로 지운 배는 브라우저에만 기억되므로(서버 데이터는 그대로), 검색으로 다시 추가하면 복원됩니다.
- 예전 버전(`localStorage` v7)에서 직접 추가·삭제한 배는 첫 실행 때 한 번만 자동 승계됩니다.

## 📲 갤럭시 홈 화면에 앱으로 추가하기

1. 갤럭시 **Chrome**에서 https://youngwon1066-max.github.io/Sung/ 를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가** (또는 주소창의 설치 아이콘 / "앱 설치" 배너)를 누릅니다.
3. 홈 화면의 **피클마린** 아이콘을 누르면 주소창 없는 앱 화면으로 열립니다.
   - 삼성 인터넷 브라우저도 **⋮ → 페이지 추가 → 홈 화면**으로 같은 방식으로 추가됩니다.

## 🛠 로컬에서 열기

정적 파일만으로 동작합니다. `fetch('./data/fleet.json')` 때문에 파일 더블클릭보다 로컬 서버를 권합니다(파일로 열면 내장 사본으로 표시).

```bash
cd pickle-marine-tracking
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## ⚠️ 데이터 안내

- 선박 위치·속도·ETA는 **운항 추적(AIS 조회)으로 확인한 관측값**을 6시간 주기로 반영한 것이며, 초 단위 실시간 AIS가 아닙니다. 지도 하단의 **VesselFinder 실시간** 링크로 교차 확인하세요.
- 지도 타일은 OpenStreetMap, 지도 라이브러리는 Leaflet(무료 오픈소스)을 사용합니다.
- 브리핑은 참고용 정보이며, 접안·도선 일정은 해당 부두/도선사 확인이 필요합니다.

## 📁 구성

```
index.html               앱 본체 (지도·브리핑·프로필 모달 + 내장 사본 1개)
data/fleet.json          선박 데이터 원본 (updatedAt + fleet[])
sw.js                    서비스 워커 v3 (fleet.json 네트워크 전용 · index.html 네트워크 우선)
manifest.json            PWA 매니페스트 (피클마린 / standalone / #0b0e14)
icons/                   앱 아이콘 192·512·maskable·apple-touch·파비콘·기본 아바타
tools/                   아이콘 생성 · fleet.json→내장 사본 동기화 스크립트
```
