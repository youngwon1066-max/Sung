# 🚢 피클마린트래킹 (Pickle Marine Tracking)

원료·제품 운반선을 한 화면에서 지켜보는 **해상 관제 웹앱**입니다. 지도 위 실시간 항적과 함께, 담당 AI 비서가 **5단계 표준 브리핑**을 말풍선으로 차례대로 읽어 줍니다.

- **바로 열기**: https://youngwon1066-max.github.io/pickle-marine-tracking/
- 설치 없이 브라우저에서 열리고, 갤럭시(안드로이드) 홈 화면에 **PWA 앱**으로 추가할 수 있습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| 🗺️ 해상 지도 관제 | Leaflet + OpenStreetMap 기반. API 키 없이 동작하며 선박 위치·과거 항적·예상 항로를 표시합니다. |
| 💬 5단계 표준 브리핑 | ① 현재 위치 → ② 속도·침로 → ③ 화물·흘수 → ④ 도착 예정일(ETA) → ⑤ 여수 중흥부두 접안·통항 조건 |
| 🧭 회랑 우회 항로 | 울산↔여수(남해 외해), 여수↔서해(고흥·여수반도 관통 방지) 구간을 실제 해로에 맞춰 곡선으로 그립니다. |
| ⚡ 감속 사유 진단 | 11~13노트 순항 대비 저속일 때 투묘·계류·Eco Steaming·협수로 제한속도 등 원인을 문장으로 설명합니다. |
| 🔎 선박 검색·추가 | 선박명 또는 IMO 번호로 조회해 관제 목록(칩)에 추가, `×`로 관제 종료. |
| 🥒 담당 피클 교체 | 비서 이름·호칭·자음 캐릭터·테마 컬러를 바꾸고, `?agent=이름&user=호칭&consonant=ㅇ&color=%23c084fc` 링크로 동료에게 그대로 공유. |
| 📱 반응형 UI | 폰 세로 화면부터 태블릿·폴더블 2단 화면(지도 / 브리핑 탭 전환)까지 대응. |
| 📲 PWA | 매니페스트 + 서비스 워커. 홈 화면 추가 시 전체 화면(standalone)으로 실행, 앱 셸은 오프라인에서도 열립니다. |

## 🚢 관제 선대 (기본 탑재)

| 선박 | IMO | 구간 | 비고 |
| --- | --- | --- | --- |
| MI LAN | 9342047 | 중국 진산 → 중국 판진 | 3,799 DWT 케미칼/석유제품 운반선, 공선 선적 대기 |
| SUNRISE SAMBU | — | 대만 안핑 → 여수 중흥부두 | 야간 도선 스케줄 맞춤 감속 운항 |
| PACIFIC SAMBU | — | 동중국해 외해 → 여수 중흥부두 | 야간 ETA |
| GRACE SAMBU | — | 울산항 → 여수 낙포부두 | 접안 완료·하역 |
| YC COSMOS | — | 대산항 → 여수/광양 석화부두 | 정박지 투묘 대기 |
| TN IDUN | — | 광양/여수항 → 대산항 석화부두 | 정박지 대기 |

선박별 항로·제원·브리핑 문구는 `index.html` 안의 `defaultFleet` 배열에서 수정합니다. 브라우저에는 마지막 상태가 `localStorage`에 저장되므로, 데이터를 새로 고치려면 **관제 초기화**(브라우저 저장소 삭제) 후 다시 열면 됩니다.

## 📲 갤럭시 홈 화면에 앱으로 추가하기

1. 갤럭시 **Chrome**에서 https://youngwon1066-max.github.io/pickle-marine-tracking/ 를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가** (또는 주소창의 설치 아이콘 / "앱 설치" 배너)를 누릅니다.
3. 홈 화면의 **피클마린** 아이콘을 누르면 주소창 없는 앱 화면으로 열립니다.
   - 삼성 인터넷 브라우저도 **⋮ → 페이지 추가 → 홈 화면**으로 같은 방식으로 추가됩니다.

## 🛠 로컬에서 열기

정적 파일만으로 동작합니다. 파일을 더블클릭해도 되지만, 서비스 워커·매니페스트 확인까지 하려면 로컬 서버로 엽니다.

```bash
cd pickle-marine-tracking
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## ⚠️ 데이터 안내

- 선박 위치·속도·ETA는 **앱에 내장된 관제 시나리오 값**이며 실시간 AIS 수신이 아닙니다. 지도 하단의 **VesselFinder 실시간** 링크로 실제 위치를 교차 확인하세요.
- 지도 타일은 OpenStreetMap, 지도 라이브러리는 Leaflet(무료 오픈소스)을 사용합니다.
- 브리핑은 참고용 정보이며, 접안·도선 일정은 해당 부두/도선사 확인이 필요합니다.

## 📁 구성

```
index.html               앱 본체 (지도·브리핑·프로필 모달 포함, 단일 파일)
manifest.json            PWA 매니페스트 (피클마린 / standalone / #0b0e14)
sw.js                    서비스 워커 (앱 셸 캐시, 지도 타일 네트워크 우선)
icons/                   앱 아이콘 192·512·maskable·apple-touch·파비콘·기본 아바타
tools/                   아이콘 생성 스크립트 (Python + Pillow)
```
